# Correspondance des fonctions et vérifications

Les exemples de validation live sont volontairement agrégés : aucun vendeur, identifiant de rangée/offre, compte, total de session, prix individuel ou chemin de produit consulté n’est publié.

Les mentions « présent », « partiel » et « absent » décrivent le code livré, pas seulement l’intention. « Vérifié » signifie qu’un scénario local ou une inspection ciblée a donné un résultat. Aucun achat, changement d’offre ou message n’est envoyé par les tests.

La page d’options conserve aussi le thème, le mode et l’ajustement de prix, le plancher, les jeux favoris, la signature, les commentaires et les permissions d’hôte. `priceShortcuts` est une liste de modes configurable, vide par défaut; le changement de schéma ne retire donc aucun bouton de calcul existant par défaut. Les valeurs anciennes inconnues sont conservées pendant la migration. Les réglages chart historiques non exposés par l’interface restent stockés mais ne sont pas contrôlables ici.

Le réglage persistant `offerLanguages` est un tableau vide par défaut (équivalent à « Toutes les langues »). L’interface propose des cases à cocher pour les 15 langues Cardmarket : Anglais, Français, Allemand, Espagnol, Italien, Chinois, Japonais, Portugais, Russe, Coréen, Chinois traditionnel, Néerlandais, Polonais, Tchèque et Hongrois, associés aux identifiants consécutifs `1` à `15`. Plusieurs langues peuvent être sélectionnées simultanément. Sur les fiches produit détaillées avec contrôle natif de langue des offres, les ID sont dédupliqués et triés puis appliqués dans un unique paramètre natif CSV, par exemple `language=2,7`; les autres paramètres et fragments sont conservés. Le garde accepte les routes de forme `/Products/<type>/<produit>` (et Singles avec extension + carte), quel que soit le type lorsque Cardmarket fournit le contrôle de langues. Les fixtures couvrent Singles, ETB, boosters, booster boxes, blisters, sealed, sets, lots et accessoires; pour ces familles hors ETB/booster bundle, elles vérifient la grammaire de route construite, pas la présence live d’une fiche Cardmarket correspondante. Les catégories racine, recherches et routes hors `Products` sont exclues. Le garde de contenu vérifie en plus une vraie entrée de langue native : case dans `#articleFilterProductLanguage` (avec ou sans `.form-check`), rôle checkbox, select `idLanguage` ou filtre flottant. La migration convertit l’ancien `offerLanguage: 'all'` en tableau vide et une ancienne valeur de langue en tableau à un élément, sans perdre les autres préférences. Le choix vide ne force rien. Un marqueur par onglet et chemin permet de restaurer le filtre natif antérieur uniquement si l’URL contient encore le CSV appliqué par l’extension; l’ancien marqueur mono `languageId` est aussi accepté. Une interaction manuelle native enregistre le chemin comme choix manuel pour préserver le filtre sur cette fiche, même si une préférence d’extension est configurée.

Cette extension ne revendique pas la parité complète.

## Modules techniques Enhanced

`classes.js`, `include.js`, `cardmarket.js` et l’enum interne `shipment-status.enum.js` fournissent types de réglages, utilitaires DOM et branchement des modules. L’extension unifiée les remplace par `core.js`, un stockage `chrome.storage.local` et un démarrage Cardmarket plus réduit. L’enum de statuts reste absent, car aucune fonction utilisateur autonome ne l’exige.

## Sites partenaires Enhanced

Sur les boutiques partenaires autorisées, le code ajoute un lien uniquement aux cartes produit reconnues : URL locale de type produit, ou carte contenant à la fois une image et un prix. Les liens de navigation, panier, pied de page et catégories sont rejetés. Le titre peut venir des données produit, d’un titre/heading, du texte du lien ou des attributs d’image `alt`/`title`. Le jeu est déduit du titre, du chemin ou du texte de carte, pour les jeux reconnus par le module. Si aucun indice n’est disponible, le repli historique reste Magic. Le lien est une recherche Cardmarket sans achat; un prix visible fiable peut transmettre la provenance au module d’aide acheteur. Le prix Mave immédiat distinct n’est pas reproduit.

Les essais pré-correction sur plusieurs boutiques partenaires ont montré des liens injectés hors produit et des recherches vides. Les helpers corrigés ne retiennent que les liens produit et utilisent le titre/contexte pour déterminer le jeu; ces résultats ont des tests locaux, mais aucune vérification live post-correctif. Aucun achat n’a été effectué.
